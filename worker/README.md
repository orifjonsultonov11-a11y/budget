# Apple Pay → «Мой бюджет»: настройка

Как это работает: при оплате телефоном команда iPhone («Команды» → автоматизация «Транзакция») отправляет сумму и название магазина на твой сервер Cloudflare. Приложение при открытии забирает платежи оттуда и удаляет их с сервера.

Нужно один раз: ~15 минут.

## 1. Ключ
Приложение → «Настройки» → «Apple Pay» → «Скопировать». Это ключ доступа для команды iPhone.

Сервер запоминает первый ключ, который пришлёт приложение (кнопка «Сохранить» с адресом сервера), и дальше принимает только его. Поэтому подключи приложение сразу после создания сервера. «Новый ключ» в приложении меняет ключ и на сервере.

## 2. Сервер Cloudflare (бесплатно)
Если сервер уже создан (например, через API) — переходи к шагу 3.

1. Зарегистрируйся на dash.cloudflare.com.
2. **Хранилище.** Слева «Storage & Databases» → «Workers KV» → «Create». Имя: `budget-queue`.
3. **Сервер.** «Workers & Pages» → «Create» → «Start with Hello World» → имя `budget-pay` → «Deploy».
4. «Edit code» → удали всё и вставь содержимое файла [`worker.js`](worker.js) → «Deploy».
5. Вкладка сервера «Settings» → «Bindings» → «Add» → «KV namespace»: Variable name `QUEUE`, namespace `budget-queue` → сохранить.
6. Необязательно: «Variables and Secrets» → секрет `KEY` с ключом из приложения. Если он задан, сервер принимает только его, а «Новый ключ» в приложении не работает — менять придётся здесь.
7. Скопируй адрес сервера вида `https://budget-pay.<имя>.workers.dev`.

## 3. Приложение
«Настройки» → «Apple Pay» → вставь адрес → «Сохранить». Статус должен стать «Подключено».

## 4. Команда на iPhone
1. «Команды» → «Автоматизация» → «+» → «Транзакция».
2. Выбери свою карту, остальное оставь «Любой». Включи «Запускать сразу» → «Далее» → «Новая пустая автоматизация».
3. Добавь действие «Получить содержимое URL»:
   - URL: `https://budget-pay.<имя>.workers.dev/add`
   - Метод: **POST**
   - Заголовки: ключ `X-Key`, значение — ключ из приложения
   - Тело запроса: **JSON**, два поля типа «Текст»:
     - `amount` — переменная «Ввод команды» → свойство «Сумма»
     - `merchant` — переменная «Ввод команды» → свойство «Продавец»
4. Готово. Оплати что-нибудь телефоном и открой приложение: платёж появится вверху вкладки «Операции».

## Как ведёт себя приложение
- Магазин встречается впервые → «Apple Pay · ждут категорию». Выбрал категорию — она запомнилась.
- Магазин уже знаком → расход записывается сам в ту же категорию. Поменял категорию у такой операции — запомнится новая.
- Магазины сравниваются без регистра, цифр и знаков: «KORZINKA SERGELI 12» и «Korzinka Sergeli 7» — один магазин.

## Если что-то не так
- Статус «Неверный ключ» — сервер запомнил другой ключ. Сбросить: Cloudflare → «Workers KV» → `budget-queue` → удалить запись `cfg:key`, затем в приложении «Сохранить».
- Платёж не пришёл — открой «Команды» → автоматизация и проверь, что она включена и стоит «Запускать сразу». Запусти её вручную: должна прийти запись.
- Сменил ключ в приложении («Новый ключ») — замени его в команде iPhone.

## Виджет
Тот же сервер отдаёт виджету короткую сводку (`/summary`). Скрипт виджета для Scriptable — в приложении: «Настройки» → «Виджет» → «Скопировать скрипт виджета». Если сервер создан раньше версии 11 приложения, обнови его код (шаг 4 выше), иначе виджет напишет, что данных нет.
